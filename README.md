# Nowhere House

Free first-person horror game for Windows PC, by [Korrocorp](https://korrocorp.com/games/nowhere-house). English and French.

This repository only hosts the downloads (no source code).

**[Download the installer (latest version)](https://github.com/KorroAi/nowhere-house/releases/latest/download/NowhereHouse-Setup.exe)** · [All releases](https://github.com/KorroAi/nowhere-house/releases) · [itch.io page](https://korrocorp.itch.io/nowhere-house)

- `NowhereHouse-Setup.exe`: installs the game (Start menu and desktop shortcuts, uninstall from Windows settings, no admin rights needed).
- `NowhereHouse-Windows.zip`: unzip and run `NowhereHouse.exe`.

The game is not code-signed yet: if Windows SmartScreen shows "Windows protected your PC", click *More info*, then *Run anyway*.

Third-party licenses are in `LICENSES.txt`, next to the game.
